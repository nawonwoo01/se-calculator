## 재현된 보안 문제와 수정

유효한 Admin 설정의 진정제 이름에 HTML 이벤트가 포함되면 빠른 용량 버튼의 `innerHTML` 조립에서 약제명만 이스케이프하지 않아 스크립트가 실행될 수 있었다. Import와 Save local 모두 가상 브라우저에서 재현했다. 무해한 테스트 표시 `window.__drugLabelExecuted`가 수정 전 두 경로 모두true였고, 주입된 이미지 요소6개가 생성됐다. 실제 악용 또는 사용자 정보 유출이 발생했다고 주장하지 않는다.

기존 `escapeHtml`을 해당 약제명에도 적용했다. 설정 값을 삭제·변환하지 않고 표시 단계에서 문자로 처리한다. 가져오기/편집/새로고침 후 실행되지 않는 브라우저 회귀 검사2건을 추가했다. 계산식·근거 카탈로그·용량·점수 기준은 보존했다.

또한 `constructor` 같은 예약된 설정 키가 검증을 통과한 뒤 가져오기 도중 오류를 일으켜, 실패 안내 후에도 잘못된 구성이 저장되는 문제를 재현했다. 약제 및 경고 식별자의 예약 키를 저장 전 검증에서 거부해 기존 구성/계산 상태를 보존한다. 브라우저 재현 회귀1건과 설정 검증 검사1건을 추가했다. 이는 설정 스키마 보완이며 의료 계산을 바꾸지 않는다.

지원 안내의 세 진정제 자동 계산과 MDZ/Ket 배수 적용 범위를 현재 앱 동작에 맞췄다. 개인정보 처리방침의 오래된 앱 버전 표기를 제거했으며 정책 내용과 기존 갱신일은 변경하지 않았다. 앱·지원·패키지 버전은0.5.1, PWA 캐시는 `se-calculator-0.5.1-web-security-1`로 갱신했다. 원문 검토일/임상 검토 상태를 새로 승인한 것으로 기록하지 않았다.

- 실제0.5.0 커밋의 정적 파일과 서비스 워커를 제공하는 임시 서버로 기존 캐시를 구성했다.0.5.1은 사용자의 적용 동작 전까지 대기하고, 적용 후 기존 가상 케이스와 Admin 설정 원문이 완전히 같은지 확인했다. 이전 캐시 제거·약제명 텍스트 처리와 계산기/개인정보/지원 페이지의 오프라인 동작도 통과했다. 이 검사는 실제 기기 전체에 대한 보증이 아니라 격리된 Chromium 프로필의 이전 버전 이행 검사다.

## 공개 접속의 근거와 한계

Cloud 작업 환경에서 공개 GitHub Pages 주소로 직접 요청하면 목적지 정책에 의해 CONNECT403으로 차단됐다. 이를 사이트 장애로 해석하지 않았다. 시작 시점에는 동일 main의10월22일 공개 검증 성공 기록만 있었으며 이를 이번 달 새 검사로 주장하지 않았다.

수정 PR의 검사를 통과시킨 뒤 main 병합·Pages 배포와 실제 공개 URL 검증을 수행한다. 완료 여부와 실행 시각은 해당 main의 `pages build and deployment`, `Web calculator checks`, `Verify deployed calculator` 실제 실행 결과를 기준으로 판단한다. 운영 검증의 파일 해시·브라우저·리소스 보고서는 `deployed-web-verification` 아티팩트에 저장된다. 이 문서만으로 실행 전의 검사를 완료로 추정하지 않는다.

외부 의학 원문의 최신성·용량 재평가는 이 월간 기술 점검에 포함하지 않았다. 외부 링크 형식 검사는 각 외부 서버의 정상 응답이나 최신 임상 근거 확인과 다르다. 기술 검증은 임상 승인이 아니다.

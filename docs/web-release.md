# 웹 업데이트0.5.1 · 월간 보안 보완

공개 사이트: https://nawonwoo01.github.io/se-calculator/

Admin 설정을 가져오거나 저장할 때 약제명에 들어 있는 HTML이 빠른 용량 버튼에서 실행될 수 있는 문제를 재현하고, 기존 HTML 이스케이프를 해당 표시에도 적용했다. 저장된 설정을 제거하지 않고 약제명을 텍스트로 표시한다. 실패한 가져오기가 잘못된 구성을 남기지 않도록 예약된 설정 키도 저장 전에 거부한다. Import·Save local 및 새로고침 뒤 실행을 막는 회귀 검사를 추가했다.

계산식·약물 용량·주입속도 기준·근거 카탈로그·임상 검토 상태를 보존했다. 지원 안내를 실제 자동 계산/N배 동작에 맞추고 개인정보 안내의 오래된 앱 버전 표기를 정리했다. 무료 웹/PWA만 유지하며 모바일 출시 PR#1은 병합하지 않는다.

Node 산술/설정12건·모바일 UI/PWA28건, 로컬 운영 시나리오2건을 통과했다. 실제 이전0.5.0 코드 캐시에서0.5.1 적용 대기/활성화, 가상 저장 케이스·설정 원문 보존 및 오프라인 동작을 추가 확인했다. 개발 의존성 검사에서 보고된 취약점은0건이었다. 상세 재현·검사 범위·공개 접속 제한은 [월간 검증 기록](maintenance/2026-11.md)에 남겼다.

공개 배포 후 파일7개SHA-256, 계산·PWA 및 리소스12개HTTP/MIME·개인정보/지원 탐색을 CI에서 검증한다. 실제 공개 검증의 완료 여부는 해당 main 실행 결과와 `deployed-web-verification` 아티팩트로 확인한다.

기존 설치본은 온라인으로 열고 계산을 마친 뒤 ‘새 버전 적용’을 눌러0.5.1을 확인한다. 저장하지 않은 현재 계산은 초기화될 수 있으며 저장 케이스와 Admin 설정은 유지된다.

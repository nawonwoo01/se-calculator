# 웹 업데이트 0.3.0

작성일: 2026-10-22. 공개 사이트: https://nawonwoo01.github.io/se-calculator/

## 체중을 먼저 입력하는 흐름

체중을 입력하면 Midazolam·Ketamine의 1배 혼합표, 선택한 수액과 N배 혼합량, 용량별 주입속도, 별도의 shooting/IV loading을 자동 표시한다. 기본 실제 체중 계산에는 키·성별·약물량 입력이 필요 없다. 키·BMI·IBW·LBW·AdjBW와 케이스 저장은 선택 항목으로 접는다. 보정 체중을 선택한 경우에는 키가 필요하며 누락 시 해당 계산값을 지운다.

다른 sedative와 직접 농도 입력, 전체 용량별 표는 상세 설정에 유지한다. 기본 자동 표는 Midazolam과 Ketamine 각각의 별도 혼합액이다. 두 약제를 같은 수액에 함께 혼합하는 안내가 아니다.

## 이번 계산기의 1배 정의

사용자가 2026-10-22에 정정한 체중kg : 100 mL당 약물mg = 1:1 기준을 적용한다. 0.2.1에서 0.2.0의 1,000 mL 기준을 100 mL로 바로잡았다. 이는 농도 환산 규칙이며 권장 처방이나 희석 안정성 검증이 아니다.

`약물 mg = 투여 체중 kg × 최종 혼합 부피 mL / 100 × N`

체중60 kg의 1배는 각 약제별로 다음과 같다.

| 최종 부피 | 약물량 |
|---|---:|
| 100 mL | 60 mg |
| 250 mL | 150 mg |
| 500 mL | 300 mg |
| 1,000 mL | 600 mg |

60 mg/100 mL를 10 mL/hr로 주면 6 mg/hr ÷60 kg = **0.1 mg/kg/hr**다. 2배 혼합액에서는 같은 0.1 mg/kg/hr가 5 mL/hr이고 10배에서는 1 mL/hr다. 수액 부피만 바꾸면 약물량도 비례하여 바뀌므로 같은 N배의 농도와 용량별 mL/hr는 유지된다.

Shooting은 혼합 배수와 별개다. 기존 기본값인 Midazolam 0.2 mg/kg, Ketamine 1 mg/kg를 재사용하며 이번 변경에서 loading 기준·반복/누적 한도·투여 속도를 새로 정하지 않는다. 약물량은 mg로 표시하며 원액 mL·앰플 수는 추정하지 않는다. 실제 제제 농도·희석 적합성·수액 부하·최종 부피를 별도로 확인한다.

## 속도 조절·수액 계획

각 약제의 cc/hr(=mL/hr)를 직접 입력하면 mg/kg/hr와 24시간 수액량, 계산상 소진시간을 표시한다. 속도를 입력하는 동안 입력칸을 재생성하지 않아 초점과 입력값을 유지한다. N배 변경은 각 약제의 현재 mg/kg/hr를 유지하는 속도로 환산한다. 분수 배수의 반올림을 반복해도 기준값을 잃지 않도록 직접 입력한 1배 상당 속도를 유지한다. 수액 부피만 바꾸면 농도·속도·하루 수액량은 유지되고 소진시간만 달라진다.

60 kg·1배·40 mL/hr의 예에서 0.4 mg/kg/hr, 960 mL/24 hr다. 100 mL는 계산상 2시간30분, 1,000 mL는 25시간에 소진된다. 2배 전환 시 같은 용량이 20 mL/hr·480 mL/24 hr로 환산된다. 소진시간은 실제 제제의 안정성 또는 허용 교체시간이 아니며, 실제 펌프 설정은 별도로 확인한다. 각 약제 혼합액 외의 수액은 이 합계에 포함하지 않는다. 0 mL/hr는 용량/수액량0·유한 소진시간 없음으로 표시하고, 빈칸·음수·범위 초과 입력은 해당 결과를 지운다. 새 케이스에서는 이전 속도와 혼합 배수를 초기화한다.

## 검증

Node 산술 검사 10건과 모바일 UI/PWA 검사 16건이 로컬에서 통과했다. 여러 체중·수액·배수 조합의 농도와 역산, 체중만 입력한 자동 표시, 속도별 용량·수액량·소진시간과 배수 변경 시 용량 유지, shooting의 배수 독립성, 선택적인 키와 보정 체중, 잘못된 입력에서 결과 제거, 기존/체중만 저장한 케이스, 직접 입력 모드·다른 약제, PE 단위·STESS, 구 캐시의 사용자 적용 전 대기·오프라인 동작을 확인한다. 기술 테스트는 임상 승인이 아니다.

PR/main CI는 같은 검사를 실행한다. 운영 검증은 main 배포 후 실제 공개 파일 6개의 SHA-256 일치와 브라우저에서의 체중 단독 입력·혼합 배수·별도 shooting·ASM·STESS·오프라인 동작을 검사한다. 실제 배포 성공은 해당 실행 결과로 확인하며 이 문서만으로 완료를 추정하지 않는다.

## 사용자가 확인하는 순서

1. 온라인에서 사이트를 열고 `v0.3.0`을 확인한다. 기존 설치본의 업데이트 안내가 보이면 계산을 마친 후 **새 버전 적용**을 누른다. 저장하지 않은 현재 입력은 초기화된다.
2. 키 없이 체중60 kg만 입력하여 1배 표의 60/150/300/600 mg를 확인한다.
3. 100 mL·1배를 선택하면 각 약제60 mg, Midazolam 0.1 mg/kg/hr에서 10 mL/hr인지 확인한다. 1,000 mL·10배에서는 각 약제6,000 mg, 같은 용량에서 1 mL/hr인지 확인한다.
4. 수액과 배수를 바꿔도 별도의 shooting은 Midazolam12 mg·Ketamine60 mg로 유지되는지 확인한다. 이는 기존 설정의 산술 예제다.
5. 체중을 지우면 이전 결과가 남지 않는지, 키 없이 케이스 저장이 가능한지 확인한다.
6. 실제 임상 범위·상한·희석 적합성·참고문헌은 `clinical-review.md`에 따라 별도로 검토한다.

## 운영 범위

사용자는 2026-10-16에 Google Play·Apple App Store 출시를 중단했다. 무료 웹/PWA만 유지하며 월간 기술 점검과 분기 근거 검토를 예약했다. 미출시 모바일 PR #1을 이 웹 업데이트에 병합하지 않는다. 기관의 공식 배포·임상·규제 승인을 확보했다고 가정하지 않는다.

이전 0.1.1에서는 입력값 검증·약제별 직접 혼합 농도·STESS·PE 단위·케이스 문자열/초기화·PWA 버전 캐시와 개인정보/지원 안내를 보완했다. 기존 브라우저의 익명 케이스와 로컬 Admin 설정은 유지한다. 0.2.0부터 기본 화면은 체중에 비례하는 자동 농도를 사용하므로, 기존에 직접 입력하던 혼합액은 상세 설정에서 **직접 입력한 혼합액 사용**을 선택해 확인한다.

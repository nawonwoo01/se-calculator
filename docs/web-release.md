# 웹 업데이트 0.4.0

작성일: 2026-10-22. 공개 사이트: https://nawonwoo01.github.io/se-calculator/

## 화면 흐름

체중을 입력하고 약제·수액 크기·배수를 선택하면 **주입속도(mL/hr)별 투여량(mg/kg/hr)의 전체 표**를 기본 화면에 표시한다. 단일 속도나 목표 용량 입력이 필요 없다. 30개 속도 행과 선택 약제 열을 함께 보여주며 표의 머리글과 속도 열을 고정한다. Propofol은 mcg/kg/min도 병기한다. 회색 셀은 기존 설정의 표시 범위 밖이며 모든 셀은 농도 환산값이지 투여 권고가 아니다.

Midazolam·Ketamine·Propofol·Pentobarbital·Thiopental 선택을 기본 화면에 복원했다. 선택 약제의 shooting/IV loading도 별도로 표시한다. 기존 전체 용량→속도표는 같은 패널의 ‘투여량 → 주입속도 · 기존 전체 용량표’를 열어 볼 수 있다. 단일 속도 입력·24시간 수액량·소진시간과 단일 목표 용량 환산은 보조 기능으로 접는다. 잘못된 단일 입력이 독립적인 전체 환산표를 지우지 않는다.

키·BMI·보정 체중은 선택 사항이다. 기본 실제 체중은 키 없이 계산한다. 보정 체중을 선택하면 키가 필요하며 누락 시 관련 결과를 지운다. 기존 익명 케이스와 로컬 Admin 설정은 유지한다. 새 케이스에서는 속도·농도·배수·주의사항을 초기화한다.

## 혼합 농도와 단위

Midazolam·Ketamine 자동 혼합식은 사용자 지정 **체중kg : 100 mL당 약물mg =1:1** 기준이다. 각 약제는 별도 혼합액이며 두 약제를 한 수액에 함께 넣는 안내가 아니다.

`약물 mg = 투여 체중 kg × 최종 혼합 부피 mL /100 × N`

60 kg의 1배는 100/250/500/1000 mL에 각각60/150/300/600 mg다. 1배10 mL/hr =0.1 mg/kg/hr, 40 mL/hr =0.4 mg/kg/hr다. 2배의 같은40 mL/hr는0.8 mg/kg/hr다.

다른 약제에 이 자동 혼합식을 임의 적용하지 않는다. Propofol·Pentobarbital·Thiopental은 실제 사용하는 **약제별 1배 총 약물량·최종 부피**를 입력한다. 각 약제의 N배 약물량은 그 1배 값×N이다. 저장된 로컬 설정이 다른 약제를 첫 약제로 선택해도 기본 농도를 가져오지 않는다. 약제 설명은 농도 입력 전에도 볼 수 있다. 농도가 없거나 잘못되면 해당 약제 열에 ‘혼합액 입력 필요’를 표시하며 다른 약제 계산은 유지한다. 약제를 해제·재선택하거나 첫 약제로 전환해도 독립적인 기준 농도를 유지하고 배수를 중복 적용하지 않는다. 기존 로컬 설정은 임상 기준으로 자동 승인되지 않는다.

Propofol의 native 단위는 mcg/kg/min이고 mg/kg/hr 환산계수는0.06이다. 예:60 kg, 1000 mg/100 mL, 30 mL/hr =5 mg/kg/hr =83.33 mcg/kg/min. N배는 산술 환산이며 실제 제형의 증량·희석 적합성을 보증하지 않는다. 약물 부피를 포함한 최종 부피와 안정성을 별도로 확인한다.

## 수액 계획과 shooting

단일 cc/hr 입력은 해당 약제의 실제 혼합 농도로 용량·24시간 수액량·소진시간을 계산한다. N배 변경 시 현재 용량을 유지하도록 각 약제 속도를 환산한다. 직접 입력하는 동안 초점을 유지한다. 자동 mix에서 수액 크기만 바꾸면 농도·속도·하루 수액량은 유지되고 소진시간만 바뀐다. 다른 약제의 직접 입력 부피는 독립적이며 자동 mix 수액 선택이 이를 덮어쓰지 않는다.

60 kg·1배·40 mL/hr에서0.4 mg/kg/hr,960 mL/24 hr다. 100 mL는 계산상2시간30분,1 L는25시간이다. 2배로 바꾸면 같은 용량에서20 mL/hr·480 mL/24 hr다. 소진시간은 안정성·실제 허용 교체시간이 아니다. 각 약제 혼합액 외 수액은 포함하지 않는다. 0속도는0용량/수액량·유한 소진시간 없음이며 빈칸·음수·범위 초과는 해당 결과를 지운다.

Shooting은 혼합 농도·배수와 독립적이다. 기존 설정값(Midazolam0.2, Ketamine1, Propofol2, Pentobarbital5, Thiopental3 mg/kg)을 그대로 재사용한다. 반복·누적 한도·주입 속도나 원액 mL·앰플 수를 새로 정하지 않는다.

## ASM 주의사항 통합

별도 Warnings 탭을 ASM loading으로 통합했다. 환자별 체크 항목을 선택하면 관련 약제 행에 ‘⚠ 주의’와 해당 사유를 표시하고, 선택한 ASM의 loading 결과 위에도 같은 주의사항을 표시한다. 해제·약제 전환·새 케이스에서 즉시 갱신한다. 원래 경고의 진정제 관련 내용과 로컬 추가 항목은 같은 화면의 전체 참고사항에 보존한다.

| 체크 항목 | 연결되는 ASM |
|---|---|
| 신장 기능 | LEV 유지용량·투석 주의, loading 자동 감량 없음 |
| 중증 간 질환·혈소판/응고장애·임신/가임·carbapenem | VPA, 각 항목별 설명 |
| 전도장애·Dravet/나트륨통로 독성 | PHT·fPHT·LAC |
| 쇼크/저혈압 | PHT·fPHT·PB |

임신 시 장기 사용과 단회 응급투여 판단은 구분한다. 주의 표시는 용량을 바꾸거나 금기를 확정하지 않는다. 연결된 경고가 없다고 안전성이 확인되었다고 표시하지 않는다. 사용자 추가 약제·경고 항목은 자동 연결하지 않으며 전체 참고사항에서 검토한다.

## 첨부 Excel 대조

사용자 제공 `AED loading dose calculator by WWL.xlsx`의 B7/B8/B9 입력과 M8/M9 혼합식, K10:M55의 긴 환산표를 대조했다. 예제65 kg·500 mL·4배 =1300 mg,0.1 mg/kg/hr =2.5 mL/hr가 일치한다. 이 구조를 UI 복원의 기준으로 사용했다.

Excel의 임상 메모·용량은 별도 승인으로 취급하지 않는다. 현재 앱과 다른 ketamine loading, PHT 용량, fPHT 질량/PE 표현, LEV/VPA 시간, 경구 TPM/PER 등의 내용을 자동으로 임상 기본값에 반영하지 않았다. 차이는 `clinical-review.md`에 기록한다. 기존 5개 진정제와6개 ASM의 용량·상한·시간·근거 목록은 이번 변경에서 유지한다.

## 검증 및 운영

로컬 Node 산술 검사와 모바일 UI/PWA 회귀 검사, PR CI를 실행한다. 전체 표의 기본 표시·전 약제 독립 농도·배수·단위·별도 shooting·잘못된 입력·주의 표시/해제/초기화·오프라인/구 PWA 업데이트를 검증한다. 실제 공개 배포는 main CI의 공개 파일6개 SHA-256 일치와 운영 브라우저 검사로 별도 확인하며 실행 결과 없이 완료로 추정하지 않는다. CI 설치는 `npm ci --no-audit`로 중복 보안 요청을 피하고, 별도의 전체 `npm audit`는30초 요청 제한·2회 재시도로 유지한다. 보안 검사 오류나 취약점을 성공으로 취급하지 않는다. 기술 검증은 임상 승인이 아니다.

확인 순서: 온라인에서 v0.4.0 확인(설치본은 ‘새 버전 적용’) → 체중60 kg 입력 →1배40 mL/hr 행0.4 확인 →2배 같은 행0.8 확인 →다른 약제 선택/농도 확인 →ASM loading에서 전도장애·간질환 등을 체크해 해당 약제 표시 확인.

2026-10-16 사용자 결정에 따라 무료 웹/PWA만 유지한다. 월간 기술 점검과 분기 근거 검토 예약을 유지하며 앱스토어 출시·등록비·미출시 PR #1 병합은 진행하지 않는다. 기관의 공식 배포·임상·규제 승인을 가정하지 않는다.

# 웹 업데이트 0.5.0 · 근거별 자동 계산

2026-10-22. 공개 사이트: https://nawonwoo01.github.io/se-calculator/

체중을 입력하고 Propofol·Pentobarbital·Thiopental을 선택하면 근거·제제 기준으로 약물량과 전체 주입속도표를 자동 표시한다. 총 약물량 입력이 필요 없다. 기존 Midazolam·Ketamine 자동1배, 모든 선택 약제의 별도 shooting, ASM 주의 표시와 저장 케이스/PWA를 유지한다.

## 선택과 계산

전체 속도표를 먼저 표시하고, 그 아래 각 약제의 용량 근거·지속주입 용량·단회 loading·제제 농도/용량을 선택할 수 있다. 선택지는 `용량_(근거·연도)` 형식이다. 범위 안의 계산 선택값을 모두 권장 시작량으로 해석하지 않는다.

| 약제 | 용량 근거 | 기본 제제·희석 농도 |
|---|---|---|
| Propofol | NCS2012: 시작20, 유지30–200 mcg/kg/min; Malter SOP2022:4–10 mg/kg/hr | 확인한10 mg/mL 완제품,20/50/100 mL |
| Pentobarbital | NCS2012: loading5–15 mg/kg, 유지0.5–5 mg/kg/hr | 확인한 Hikma50 mg/mL 제품,20/50 mL |
| Thiopental | NCS2012: loading2–7, 유지0.5–5; SOP2022:loading5, 유지3–7 mg/kg/hr | Panpharma SmPC의0.2%/0.4%(2/4 mg/mL), NS/D5W 조제·중심정맥 |

NCS의 기존 단회 기본 선택값(Propofol2/Pentobarbital5/Thiopental3 mg/kg)을 보존했다. Loading 선택값은 범위 안의 단회 계산이며 반복·누적 투여나 기간을 지시하지 않는다. SOP는 우월성이 확정된 새 지침이 아니라 실무 SOP로 구분한다. 새 문헌이라는 이유만으로 범위를 합치거나 기본값을 덮어쓰지 않는다.

용량 근거와 제제·희석 근거는 별개다. Pentobarbital 라벨의50 mg/mL를 RSE 지속주입 허가로 해석하지 않는다. 해당 제품은 다른 용액과 혼합 금지이며 국내 실제 제제·기관 프로토콜을 확인해야 한다. Thiopental 희석 농도 SmPC도 SE 용량 지침을 대신하지 않는다. Propofol은 NS 대용량 수액에 혼합하거나 N배로 농축하는 안내가 아니다.

MDZ/Ket의 체중mg/최종100 mL 정의와 N배는 그대로다. 다른 세 약제의 농도·용량 선택은 독립적이며 MDZ/Ket N배·수액 크기가 이를 덮어쓰지 않는다. 약제별 수액량·소진시간과 전체 표는 같은 실제 선택 농도를 사용한다. 정상 농도 변경에서는 보조 속도를 같은 mg/kg/hr로 환산하고, 빈칸 속도를0으로 바꾸지 않는다. 제제 소진시간과 안정성/허용 교체시간은 구분한다.

근거를 바꾸면 선택 용량·단위·loading·표의 범위와 주의문을 함께 갱신한다. SOP Propofol은 mg/kg/hr, NCS는 mcg/kg/min으로 선택하며 전체 표는 mg/kg/hr와 Propofol mcg/kg/min을 함께 표시한다. 일반 추가 용량 입력은 선택 근거/단위가 바뀔 때 재설정한다. 새 케이스는 근거·용량·제제 선택도 초기화한다.

고급 직접 입력 모드는 보존한다. 로컬 Admin 설정은 소실되지 않지만, 근거가 연결된 세 약제의 자동 모드에서는 연결된 원문 값이 우선한다. 직접 입력 모드는 로컬 설정과 약제별 혼합액을 사용한다.

## 날짜별 근거 관리와 운영

`evidence-catalog.js`에 출처·발표/개정일·원문 대조일·적용 대상·주의사항, 날짜별 이전/이후 값과 변경 고려사항을 구조화한다. Evidence 화면은 이 누적 기록과 원문 링크를 보여준다. 실제 검토 기록: [2026-10-22](evidence-review/2026-10-22.md). 기술 테스트는 임상 승인이 아니며 기관 최종 검토 상태는 미확인이다.

사용자 요청으로 기존 근거 검토 예약을6개월 간격으로 변경했다. 다음은2027-04-15 08:00 Asia/Seoul이고 이후4/10월15일이다. 문헌 목록만 덧붙이지 않고 실제 약물 용량·시작/유지·loading·농도·기간·안전성 차이를 비교하고 기록하도록 프롬프트를 수정했다. 임상 계산/용량 변경은 원문 비교 PR과 임상 검토 절차를 유지한다. 월간 오류/접속 점검과 무료 웹/PWA 운영은 유지하며 스토어 출시는 재개하지 않는다.

## 검증

로컬 산술11건과 UI/PWA24건이 통과했고 별도의 운영 검증 시나리오도 로컬에서 통과했다. 산술 검사는 제품 농도 자동 산출, 두 Propofol 단위, Pentobarbital·Thiopental 속도와 잘못된 값을 검사한다. UI/PWA 검사는 세 약제의 무입력 자동 계산·근거 전환·단위·loading·기존 전체 표·독립적인 농도/배수·케이스 초기화·ASM 주의·오프라인·구 캐시 갱신을 확인한다. 공개 검증 대상은 새 근거 파일을 포함한7개 파일 SHA-256과 실제 브라우저 계산이다. 실제 배포 성공은 해당 CI 결과로 확인한다.

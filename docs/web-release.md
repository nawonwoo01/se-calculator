# 웹 업데이트 0.1.1

작성일: 2026-10-15. 공개 사이트: https://nawonwoo01.github.io/se-calculator/

이 배포는 기존 웹/PWA의 오류 수정을 반영한다. 미출시 Android/iOS 프로젝트와 스토어 제출은 별도 작업이다. 사용자가 연구실은 본인이 만든 명칭이며 별도 법적 조직이 아니라고 확인했다. 연구실 명칭이나 저자의 소속을 기관의 출시 승인으로 취급하지 않는다. 임상·규제 승인도 아직 확인되지 않았다.

## 반영 내용

- 빈칸·0·음수 등의 잘못된 입력에서 이전 계산 결과를 제거한다.
- 비교하는 진정제에 각각의 혼합액을 입력하고 주 약제 변경 시 해당 농도와 용량 단위를 적용한다.
- Fosphenytoin을 mg PE로 표시하고 STESS stupor/coma 항목과 총점 경계를 수정한다.
- 케이스 전환 시 경고·점수를 초기화하고 케이스/설정 문자열을 안전하게 표시한다.
- 체중·키는 빈칸에서 시작한다. 기존 브라우저에 저장한 케이스는 유지하며 환자 식별정보 입력을 안내하지 않는다.
- 로컬 Admin 설정의 구조·수치 검증을 추가한다. 기존 로컬 설정이 있으면 해당 기기에서는 기본값과 다른 값이 적용될 수 있다.
- PWA 파일을 한 버전으로 캐시하고 사용자가 새 버전 적용을 선택하게 한다. 구 v8 service worker에서의 갱신과 오프라인 계산을 시험한다.
- 웹 운영자·GitHub 문의 경로·브라우저 저장/삭제 설명을 개인정보·지원 페이지에 반영한다.

## 개발 검증

로컬에서 산술 5건, 모바일 UI/PWA 9건을 통과했고 npm audit 보고는 0건이다. 구 버전 캐시에서 새 버전 안내가 나타나도 현재 입력을 자동으로 지우지 않으며, 사용자가 적용한 뒤 새 캐시로 바뀌는 것을 확인했다. 별칭과 체중 등 기존 브라우저 케이스도 유지하는 것을 시험했다. 모바일 화면을 로컬 브라우저에서 직접 확인했다.

`Web calculator checks`는 PR과 main에서 같은 검사를 수행한다. `Verify deployed calculator`는 main 갱신 시 공개 URL에 현재 파일이 반영될 때까지 기다린 뒤 HTML/JS/CSS/service worker 파일 해시, 버전 표시, 계산 예제, STESS, 잘못된 입력 처리와 오프라인 페이지 이동을 확인한다. 실제 배포 완료 여부는 이 문서의 작성만으로 추정하지 말고 해당 실행 결과에서 확인한다.

## 사용자가 검토하는 순서

1. 온라인에서 사이트를 열고 상단의 `v0.1.1`을 확인한다.
2. 기존 홈 화면 설치본에 업데이트 안내가 보이면 계산을 마친 후 **새 버전 적용**을 누른다. 적용 시 저장하지 않은 현재 입력은 초기화된다.
3. 체중60 kg/키170 cm, Midazolam 600 mg/500 mL와 0.2 mg/kg/hr의 산술 예제에서 10 mL/hr 표시를 확인한다. 이는 산술 확인 예제이며 투여 권고가 아니다.
4. 비교 약제를 선택하면 해당 약제의 별도 혼합액 입력이 필요한지 확인한다.
5. 빈칸이나 최종 부피0 입력 시 이전 결과가 사라지는지 확인한다.
6. 실제 임상 범위·최대 주입속도·불완전한 참고문헌은 `clinical-review.md`에 따라 별도로 검토한다.

## 운영과 스토어

웹/PWA는 계속 제공할 수 있다. 홈 화면 추가는 스토어 심사나 임상 승인을 뜻하지 않는다. 별도 법적 주체가 없는 연구실의 명칭만으로 Google 의료 앱 조직 계정이나 Apple 약물 용량 계산기 출처 요건을 충족했다고 기록하지 않는다. 병원·대학 등 적격 주체와의 공식 배포 협력, 적격 출판사와의 협력 또는 적용 가능한 규제 경로는 실제 권한과 정책을 확인한 뒤 검토한다.

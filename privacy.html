브라우저에 보관하는 자료

사용자가 저장 버튼을 누른 케이스와 로컬 Admin 설정은 해당 브라우저의 localStorage에 저장됩니다. “모든 케이스 삭제”, Admin의 “Reset” 또는 브라우저의 사이트 데이터 삭제로 제거할 수 있습니다. 이전 버전에서 저장한 자료도 이 브라우저에 남아 있을 수 있으므로 식별정보를 저장했다면 삭제해 주세요. 오프라인 실행을 위해 앱의 정적 파일을 캐시합니다.

사이트 접속과 외부 링크

이 사이트는 GitHub Pages에서 제공됩니다. 호스팅 서비스는 사이트 접속 시 IP 주소 등 접속 정보를 처리할 수 있으며, GitHub 개인정보 처리방침이 적용됩니다. 참고문헌 등의 외부 링크를 열면 해당 사이트의 정책이 적용됩니다.

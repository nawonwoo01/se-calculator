SE Calculator는 회원가입, 광고, 분석 SDK, 추적 기능을 사용하지 않습니다. 입력한 체중·키·성별과 계산 항목은 기기에서 계산하며 개발자 서버로 전송하지 않습니다. 환자 이름·이니셜·병록번호 등 식별정보를 입력하지 마세요.

Android·iOS 앱

계산 자료와 임시 케이스는 앱 실행 중 메모리에만 보관하며 앱을 다시 시작하면 삭제됩니다. 계산에 네트워크가 필요하지 않습니다. 카메라·사진·위치·연락처 권한을 요청하지 않습니다.

웹앱

사용자가 저장 버튼을 누른 익명 케이스와 로컬 Admin 설정은 현재 브라우저의 localStorage에 저장됩니다. 계산 화면의 “모든 케이스 삭제”와 Admin의 “Reset” 또는 브라우저 사이트 데이터 삭제로 제거할 수 있습니다. 오프라인 사용을 위해 정적 앱 파일을 캐시합니다. 웹 호스팅 제공자는 사이트 접속 시 IP 주소 등 통상적인 접속 로그를 처리할 수 있으며, 해당 서비스의 정책이 적용됩니다.

외부 링크 및 지원 문의

참고문헌 등 외부 링크를 열면 해당 사이트의 개인정보 정책이 적용됩니다. 지원 문의에 환자정보를 포함하지 마세요. 이메일 문의 자료의 처리 주체·보관기간은 출시 운영자가 정해야 합니다.
